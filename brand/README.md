# Pivyon brand kit

## Logo
The mark is a lowercase **p**: a paper-white stem and the **lime dot** — the point everything converges to in the film and the optimum the site's optimizer descends to.

| File | Use |
|---|---|
| `pivyon-mark.svg` | Mark on dark backgrounds (transparent) |
| `pivyon-mark-on-ink.svg` | Mark on its own black square — favicon, app icons |
| `pivyon-mark-dark.svg` | One-colour black mark for light or lime backgrounds |
| `pivyon-wordmark-dark.png` / `-light.png` / `-transparent.png` | Mark + PIVYON wordmark |
| `pivyon-avatar-400.png` (`-800` for high-res) | Profile picture: X, LinkedIn, GitHub |
| `pivyon-x-banner-1500x500.png` (`-3000x1000` for high-res) | X header |

Keep clear space around the mark of at least the dot's radius. Don't recolour the dot or stretch the mark.
